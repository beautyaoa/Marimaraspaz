Guia do staff

Rascunho vs Publicar

  • Guardar rascunho — só este telemóvel/browser. Útil para testar a loja no mesmo aparelho.
  • Publicar na loja — envia o catálogo para a cloud; todos os clientes vêem no próximo refresh.

Produtos

  • Use «Novo produto» ou Editar. Pode carregar foto directamente no formulário.
  • Categoria: skincare, body, deo, hair (filtros da loja).
  • Marque «Consulte» se o preço não for fixo.

Imagens do site

  • Cada cartão é um sítio da página (hero, logo…).
  • Carregar envia para a cloud e associa ao slot.
  • Média abre a biblioteca — toque numa imagem para atribuir.
  • Original volta à imagem por defeito do site.

Telemóvel

  • Botões Guardar / Publicar ficam fixos em baixo.
  • Se algo falhar no upload: confirme que o preset marimaraspaz_media existe no Cloudinary (unsigned).
  • Se publicar falhar: o Worker pode não estar deployado — contacte o programador.

Segurança

  • Altere a password de admin após a entrega.
  • Não partilhe a password do painel em grupos públicos.
